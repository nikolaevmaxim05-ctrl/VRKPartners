# Задача: добавить кнопку «Або напишіть нам» (Telegram) рядом с каждой CTA-кнопкой

Проект VRK Partners (Next.js App Router, лендинг на uk-UA).

## Что нужно

Везде на лендинге, где стоит CTA-кнопка или пара CTA-кнопок (например, «Отримати консультацію →» + «Замовити аудит Google Ads» — в hero, и любые другие CTA по секциям: в блоках услуг, кейсов, финальном CTA перед формой, шапке, если там есть кнопка), добавить рядом ещё одну кнопку:

- Текст: **«Або напишіть нам»**
- Ссылка: **https://t.me/Chuev_VRK_Partners**
- Открывается в новой вкладке: `target="_blank"` + `rel="noopener noreferrer"`.

## Как реализовать

1. **Сначала найди ВСЕ места с CTA.** Пройдись по секциям лендинга (Hero, услуги, кейсы/Trust, финальный CTA, шапка, мобильное меню — всё, где есть кнопки, ведущие к форме заявки). Составь список и добавь Telegram-кнопку в каждое. Формы (submit-кнопку LeadForm) не трогать — речь только про CTA, ведущие к заявке/консультации.
2. **Один переиспользуемый компонент** `TelegramCtaButton` (или проп у существующего компонента кнопки, если он есть) — не копипастить разметку по секциям.
3. **Ссылку не хардкодить по местам**: вынести в конфиг контента (config/site.ts, поле вида `contacts.telegramUrl` или рядом с существующими контактами) и использовать её в компоненте. Если контакты уже редактируются через контент-редактор админки — прокинь и это поле туда же (текст кнопки + URL), чтобы клиент мог сменить ссылку без деплоя. При сохранении в админке URL валидировать: только `https://t.me/...` или `https://telegram.me/...`.
4. **Стиль:** посмотри на существующую пару кнопок (жёлтая primary + тёмная secondary с рамкой). Telegram-кнопка не должна конкурировать с основной CTA — оформи её в том же стиле, что вторичная («Замовити аудит Google Ads»): та же высота и скругление, тёмная с рамкой. По желанию — маленькая иконка Telegram (инлайн-SVG, БЕЗ новых зависимостей и без иконок-паков). Где кнопок уже две — третья встаёт в тот же ряд; на мобильной ширине кнопки складываются в столбик на всю ширину, проверь, что ряд не ломается и ничего не вылезает за экран.
5. **Аналитика:** в проекте реестр событий + контракт-тест. Добавь событие клика (например, `telegram_click` с параметром секции/места) ПРАВИЛЬНО: сначала регистрируешь в реестре, потом используешь track() — контракт-тест должен оставаться зелёным. Одно событие с параметром placement, а не отдельное имя на каждую секцию.
6. Лендинг должен остаться лёгким: никаких новых библиотек, компонент — серверный или минимальный клиентский (клиентский только если нужен track на клик).

## Проверка

1. `npm run build`, линт, `npm test` (включая контракт-тест аналитики) — зелёные.
2. Ручной smoke: кнопка есть во ВСЕХ найденных CTA-местах (перечисли их в отчёте), ссылка ведёт на https://t.me/Chuev_VRK_Partners и открывается в новой вкладке, вёрстка ок на десктопе и на мобильном (360px), основная CTA визуально осталась главной.
3. Если поле прокинуто в контент-редактор: смена URL в админке меняет ссылку на лендинге, невалидный URL (не t.me) не сохраняется.
4. В отчёте: список секций, куда добавлена кнопка; где лежит URL; имя добавленного события аналитики.
