# Задача: изменить поведение клика по телефону/почте — без открытия Outlook, только копирование; исключение — телефон на мобильных

Проект VRK Partners (Next.js, лендинг + админка, uk-UA). Это правка УЖЕ реализованного поведения (компонент копирования контактов + toast «Скопійовано», коммит feat(contacts)): сейчас клик копирует значение И пропускает переход по tel:/mailto:, из-за чего на ПК открывается Outlook. Это нужно убрать.

## Новое поведение

Найди существующий компонент контактов (CopyContactLink / useCopyToClipboard или как он назван) и измени логику:

| Что | Устройство | Поведение по клику |
|---|---|---|
| **Email** | ПК и мобильные — везде | ТОЛЬКО копирование + toast «Скопійовано». Никакого mailto:/Outlook/почтового приложения: `e.preventDefault()` всегда |
| **Телефон** | ПК | ТОЛЬКО копирование + toast. Никакого tel:-перехода: `e.preventDefault()` |
| **Телефон** | Мобильные (тач-устройства) | Стандартный переход по `tel:` — открывается звонилка/контакты с уже введённым номером. Копирование и toast НЕ нужны (не мешать нативному поведению) |

## Детали реализации

1. **Определение «мобильный» — в момент клика, а не при рендере**, чтобы не было расхождений SSR/гидрации: в onClick проверять `window.matchMedia('(hover: none) and (pointer: coarse)').matches`. true → тач-устройство (телефон/планшет): для телефона пропускаем дефолтный tel:-переход; false (ПК, включая ноут с тачскрином и мышью) → preventDefault + копирование. НЕ использовать user-agent-снифинг.
2. **href оставить в разметке** (`tel:`/`mailto:`) — для семантики, доступности и правого клика «копировать адрес»; блокируется только левый клик через preventDefault по правилам таблицы.
3. Копируемые значения — как уже реализовано: телефон `+380XXXXXXXXX` без маски, email в нижнем регистре. Toast и его текст не менять.
4. На ПК у ссылок курсор `pointer` и подсказка `title="Натисніть, щоб скопіювати"` (uk-UA), чтобы было понятно, что клик копирует, а не звонит.
5. Область действия — все места, где компонент уже применён: лендинг (шапка, футер, контакты) и админка (список лидов, карточка лида). Если какие-то телефоны/почты остались вне компонента — подключи и их.
6. Существующие track()-события кликов по контактам не ломать: события должны срабатывать как раньше в обеих ветках (и при копировании, и при tel:-переходе на мобильном).
7. Никаких новых зависимостей.

## Проверка

1. `npm run build`, линт, `npm test` — зелёные. Если на компонент/хук есть тесты — обнови под новую логику и добавь кейсы: email-клик всегда preventDefault; телефон-клик preventDefault на ПК и НЕ preventDefault на таче (matchMedia замокать).
2. Ручной smoke:
   - ПК: клик по email в футере → Outlook/почтовик НЕ открывается, значение в буфере, toast показан; то же для телефона;
   - ПК, админка: копирование в списке лидов и карточке лида работает, ничего не открывается;
   - Мобильный (или эмуляция тача в DevTools): тап по номеру → открывается набор номера с подставленным номером; тап по email → копирование + toast, почтовое приложение не открывается;
   - Правый клик по ссылке на ПК → в меню доступно «Копировать адрес» (href на месте).
3. В отчёте: список изменённых файлов и подтверждение по каждой строке таблицы поведения.
